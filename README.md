# Agentic Science Lab

用于 Agentic Science Challenge 与科学计算实践的公开工作仓库：保留可核验的解题过程，复盘失败与成功，并逐步沉淀可复用的 Skill 和代码模块。

## 从这里开始

1. 所有 Agent 先读 [AGENTS.md](AGENTS.md)。
2. 查看 [当前进度](docs/status.md)，选择题目并确认其规则与评分要求。
3. 复制 [单题模板](templates/task/README.md) 到 `tasks/<challenge-id>/README.md`，在独立分支与工作目录中完成工作。
4. 保存实际运行和验证证据，通过审查后合并；再决定是否提炼 Skill 或公共模块。

## 资产布局

| 路径 | 用途 |
| --- | --- |
| `tasks/` | 单题代码、方法说明、验证回执与复盘 |
| `skills/` | 有来源、适用边界和验证记录的可复用方法 |
| `modules/` | 数据处理、科学计算、输出校验等公共代码 |
| `templates/task/` | 单题记录的最小模板 |
| `docs/` | 协作流程与当前进度 |

[协作方式](docs/collaboration.md) · [环境与平台说明](docs/platform.md)

## 公开内容与本地材料

本仓库公开。仅提交有权公开的原创代码、精简复盘、允许公开的结果和经过脱敏的验证记录。题面、数据、参考论文和第三方代码各自遵循其发布条款；公开可下载不代表可以再分发。

大型数据、模型权重、原始运行轨迹和登录凭据留在仓库外，通过来源、版本、校验值及平台 attempt ID 关联。不要把隐藏测试、标准答案或账号密钥写进仓库。`.gitignore` 只是辅助，发布前仍须检查实际暂存内容。
