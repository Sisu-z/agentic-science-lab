## 公开与受控材料

本仓库公开。此目录和 Issues 只保存组织约定、公开规则来源、脱敏状态及证据指针。比赛题面、数据、个人材料、原始轨迹、正式解题源码及答案默认留在仓库外的受控共同位置，待公开范围核实后再决定是否发布。维护者无需为协作另行公开自己的简历。

总监在本地指挥文件登记实际共同路径、当前聊天入口及轨迹来源；公开文档不记录私人绝对路径、凭据、个人身份键。任务中的受控附件以逻辑名称和校验值关联，拥有访问能力的成员才参与交付。

## 中断后五步接手

1. 读取仓库 `AGENTS.md`、本入口与官方当前通知。
2. 读取未关闭 Issues 及相关 PR，确认唯一有效 `run_id`、修订、基线和依赖。
3. 核对本地受控指挥文件、真实产物、版本及原始证据，不从旧聊天猜进度。
4. 先处理待审、阻塞、待评测和临近截止事项；不得自动启动所有角色。
5. 由总监回填一次简明汇报：完成、证据、风险、下一步、需要维护者亲做的事项。

陪跑通过当前总监聊天的任务执行开展，不设置后台轮询或自动唤醒。组织资料提供可接手入口；执行中的总监持续派工和验收，不要求维护者逐步催办或搬运报告。
