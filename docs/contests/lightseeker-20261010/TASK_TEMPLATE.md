# 单题派工模板

由总监填写到一个 Issue；此文件不是第二套实时任务表。受限内容只用逻辑名称指向共同受控材料，不贴正式题面或答案。

```text
目标：
任务ID：仓库#Issue；修订：
状态：待做/可做/执行中/待审待测/已接受/阻塞/取消
当前唯一 run_id：
基线：代码提交 / 输入版本 / 官方题面读取时间
challenge ID 与官方链接：
本赛道计分关系、必做/可选、分项门槛：
允许工具/依赖/联网/资源/时间边界：
前置依赖与共用接口：
可改目录及唯一提交操作者：
共同受控材料入口（本地指挥文件登记）：
产物：文件名、入口、格式、复现材料、真实轨迹
验收：与题目目标对应的独立检查 + 干净目录重放 + 包/轨迹校验
本轮投入边界与下次检查时间：
停止/上报条件：
结果回填：本Issue评论；候选公开改动关联PR
```

结果回填：

```text
任务ID/修订/run_id/基线：
准确产物版本与校验值：
实际执行环境、输入、步骤：
正确性/复现/包/轨迹检查及结果：
平台attempt与接收/评分状态（已获相应公开授权时）：
尚未验证与已知限制：
失败尝试摘要和下一项区分检查：
是否影响合同、依赖、其他任务：
总监接受结论及证据：
```
