## 两项必做入口

1. [追光者集结：简历与身份绑定练习](https://play.bohrium.com/challenge/playground-cli-practice-for-uploading-a-privacy-mi-dd78f10d)。需本人简历（PDF/DOC/DOCX，非空）与 `identity_manifest.json`。身份键优先招募登记 ID，题面亦允许用于登记的邮箱/手机号；不得填身份证或银行卡。隐私确认必须由本人作出，不替其猜测填写。题面说明满分代表清单和文件检查通过，**不承诺已经自动写入招聘系统**。
2. [DeePMD / DPA4 原理与进展](https://play.bohrium.com/challenge/ai4s-deepmd-dpa4-2fde8de2)。官方赛事页标为所有选手必做；正式题面、输出合同和计分关系开赛时核对。

身份绑定题可能承担赛前签到功能；不能据此把其他正式题提前做完。若签到窗口与总体比赛期间要求有疑问，先核官方题面/通知，保留来源与时间。

## 预检发现与未确认项

- 现有 Agent 认证及归属确认已现场核对；岗位投递、必做绑定题完成和招聘系统最终关联仍需分别确认。
- 本机 Playground 0.1.39，官方工具提示 0.1.40；旧版创建 attempt 时未附完整原生 `raw_messages` 文件，新版修复该接口。新版包完整性及本地无提交预检已完成，升级执行遵守维护者的安装确认要求。
- 具体正式题清单、跨题得分归属、部分分/门槛、逐题资源/联网/依赖限制：按开赛后题面核对。
- 通用说明允许重复提交，但未证明没有冷却、限流、单次大小或执行超时。以当前帮助和反馈为准。
- 新版没有 Codex 子成员轨迹自动归并。已用本轮少量逐字原生事件完成格式及无网络 dry-run 检查，证明本地样本可解析/打包；不证明正式完整轨迹会被评分器正确消费。截止按接收还是评测完成计算亦未做端到端验证。提早交有效版本，不能赌最后一分钟。
- 官方群最新更改及个人报名状态无法由匿名页面证明。需要维护者提供与本次有关的更新，技术内容由总监消化。

这些是具体待核事项，不得用历史教程参数、旧分数或“工具可运行”填补。
